# UI-02: Validate Settings panel passes synthetic config to subprocess

**Test Type:** Integration  
**Status:** PASS  
**Reference:** `testing/phase_4/UI-02.md`

---

## Prerequisites

- Local API server running from the `server` directory on port 5001.

---

## Steps to Reproduce

1. Open **Postman** (or use the Dashboard UI).
2. Create a new `POST` request to `http://localhost:5001/api/run/synthetic`.
3. In the **Body** tab, select **raw** and **JSON**. Provide a custom config:
   ```json
   {
     "n_normal_users": 10,
     "n_insider_users": 2,
     "n_days": 15
   }
   ```
4. Click **Send** to trigger the background subprocess.
5. Wait for the subprocess to complete (this could take up to a minute depending on your CPU).

---

## Expected Output

The Flask API will read the JSON, map the values to `SYNTH_N_NORMAL_USERS` environment variables, and trigger `synthetic_generator.py` using `subprocess.run()`. It will then pipe the terminal output back into the HTTP response.

**Response:**
```json
{
  "ok": true,
  "output": "[synth] Loading CERT baseline statistics...\n[synth] Generating 10 normal users over 15 days...\n[synth] Generating 2 insider users..."
}
```
