# ML-01: Create a baseline population matching CERT parameters

**Test Type:** Unit  
**Status:** PASS  
**Reference:** `testing/phase_3/ML-01.md`

---

## Prerequisites

- Python 3.10+ installed
- Run from the `local_pipeline` directory

---

## Steps to Reproduce

1. Open a PowerShell or Terminal window and navigate to the `local_pipeline` directory.
2. Open a Python shell:
   ```
   python
   ```
3. Import the synthetic generator module:
   ```python
   import pandas as pd
   from pathlib import Path
   import synthetic_generator
   
   synthetic_generator.N_NORMAL_USERS = 5
   synthetic_generator.N_INSIDER_USERS = 1
   synthetic_generator.N_DAYS = 30
   ```
5. Run the generator to an output CSV (using a Path object):
   ```python
   synthetic_generator.generate(Path("output/mock_synthetic.csv"))
   ```
6. Read the CSV and count the distinct users to verify the generator honored the configuration:
   ```python
   df = pd.read_csv("output/mock_synthetic.csv")
   insiders = df[df['insider_label'] == 1]['user'].nunique()
   normal = df[df['insider_label'] == 0]['user'].nunique()
   
   print(f"Total Rows: {len(df)}")
   print(f"Normal Users Generated: {normal}")
   print(f"Insider Users Generated: {insiders}")
   ```
