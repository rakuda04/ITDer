## Prerequisites

## Steps to Reproduce

1. Open a PowerShell or Terminal window and navigate to the `local_pipeline` directory.
2. Open a Python shell:
   ```
   python
   ```
3. Import `numpy` and your inference module's score builder:
   ```python
   import numpy as np
   from inference import _build_combined, CONFIG
   ```
4. Define some mock output arrays simulating what the Machine Learning models would return for a highly anomalous row (e.g. extremely negative IsoForest scores):
   ```python
   supervised = np.array([0.9])
   iso_scores = np.array([-0.5])
   lof_scores = np.array([-0.8])
   iso_preds  = np.array([-1])
   lof_preds  = np.array([-1])
   
   thresholds = {'iso_score_min': -1.0, 'iso_score_max': 0.0}
   ```
5. Pass the raw ML scores through your custom `_build_combined` function to see how it mathematically scales and weights the scores based on the `CONFIG`:
   ```python
   combined, unsup, iso_norm, lof_norm = _build_combined(
       supervised, iso_scores, lof_scores, iso_preds, lof_preds, thresholds
   )
   
   print(f"Normalized Iso Score: {iso_norm[0]:.4f}")
   print(f"Final Combined Risk Score: {combined[0]:.4f}")
   ```
