# ML-04: Trigger `inference_worker.py` to execute a full run

**Test Type:** Integration  
**Status:** PASS  
**Reference:** `testing/phase_3/ML-04.md`

---

## Prerequisites

- The backend API servers must be running (`docker compose up -d` in `dist/server`).
- You must have preprocessed data sitting in the database (run an ingest first, e.g., via `ING-03`).

---

## Steps to Reproduce

1. Open **Postman** (or use your terminal with `curl`).
2. Create a new request:
   - **Method:** `POST`
   - **URL:** `http://localhost:8001/run`
3. Send the request. This hits the internal REST API on the inference worker container, triggering it to pull data from Postgres, run the synthetic pipeline, run the machine learning ensembles, and calculate SHAP values.
4. Open the Docker dashboard (or use `docker logs`) and look at the logs for the `inference_worker` container.
   ```bash
   docker logs server-worker-1 --tail 50
   ```
