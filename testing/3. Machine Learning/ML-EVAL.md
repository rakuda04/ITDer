## Steps to Reproduce

1. Open a PowerShell or Terminal window and navigate to the `local_pipeline` directory.
2. Create a temporary script named `evaluate_metrics.py` (or simply open a Python shell and paste the following block). This script maps the raw predictions from the pipeline output against the true `insider_label` generated by the synthetic script.

```python
import pandas as pd
import numpy as np
from sklearn.metrics import precision_score, recall_score, f1_score, roc_auc_score, confusion_matrix

def calculate_metrics(y_true, y_pred, y_prob=None):
    prec = precision_score(y_true, y_pred, zero_division=0)
    rec  = recall_score(y_true, y_pred, zero_division=0)
    f1   = f1_score(y_true, y_pred, zero_division=0)
    
    # Calculate False Positive Rate
    tn, fp, fn, tp = confusion_matrix(y_true, y_pred).ravel()
    fpr = fp / (fp + tn) if (fp + tn) > 0 else 0.0
    
    auc = roc_auc_score(y_true, y_prob) if y_prob is not None else np.nan
    return f"{prec:.2f}", f"{rec:.2f}", f"{f1:.2f}", f"{auc:.2f}", f"{fpr:.2f}"

def run_evaluation():
    # Load ground truth and predictions
    print("Loading datasets...")
    scores_df = pd.read_csv("output/local_report_daily.csv")
    
    # local_report_daily.csv already contains insider_label written by inference.py
    # Use it directly — no need to merge with synthetic_population.csv
    merged = scores_df.dropna(subset=['insider_label'])
    
    y_true = merged['insider_label'].astype(int).values
    
    # Random Forest (Supervised)
    # RF outputs probability; we threshold at 0.5 for binary pred
    y_prob_rf = merged['supervised_score'].values
    y_pred_rf = (y_prob_rf > 0.5).astype(int)
    rf_mets = calculate_metrics(y_true, y_pred_rf, y_prob_rf)
    
    # Isolation Forest
    # -1 is anomaly, 1 is normal -> map to 1 (anomaly) and 0 (normal)
    y_pred_iso = (merged['iso_prediction'] == -1).astype(int)
    # iso_score_norm is already normalized so higher = more anomalous
    # Do NOT invert — using it directly gives correct AUC direction
    y_prob_iso = merged['iso_score_norm'].values
    iso_mets = calculate_metrics(y_true, y_pred_iso, y_prob_iso)
    
    # Elliptic Envelope
    # Note: inference.py stores Elliptic Envelope results in columns named
    # 'lof_prediction' and 'lof_score_norm' — this is a naming quirk in the
    # codebase. The underlying model IS Elliptic Envelope, not LOF.
    y_pred_env = (merged['lof_prediction'] == -1).astype(int)
    # Same fix — lof_score_norm is already anomaly-direction normalized
    y_prob_env = merged['lof_score_norm'].values
    env_mets = calculate_metrics(y_true, y_pred_env, y_prob_env)
    
    # Combined Ensemble
    y_pred_ens = merged['above_threshold'].values
    y_prob_ens = merged['combined_risk_score'].values
    ens_mets = calculate_metrics(y_true, y_pred_ens, y_prob_ens)
    
    # Print the markdown table
    print("\n## 6.8.1 Individual Model Performance\n")
    print("|**Model**|**Precision**|**Recall**|**F1-Score**|**AUC-ROC**|**False Positive Rate**|")
    print("|---|---|---|---|---|---|")
    print(f"|Random Forest (Supervised)|{rf_mets[0]}|{rf_mets[1]}|{rf_mets[2]}|{rf_mets[3]}|{rf_mets[4]}|")
    print(f"|IsoForest (Unsupervised)|{iso_mets[0]}|{iso_mets[1]}|{iso_mets[2]}|{iso_mets[3]}|{iso_mets[4]}|")
    print(f"|Elliptic Envelope (Unsupervised)|{env_mets[0]}|{env_mets[1]}|{env_mets[2]}|{env_mets[3]}|{env_mets[4]}|")
    print(f"|**Combined Ensemble**|**{ens_mets[0]}**|**{ens_mets[1]}**|**{ens_mets[2]}**|**{ens_mets[3]}**|**{ens_mets[4]}**|")

if __name__ == "__main__":
    run_evaluation()
```

3. Run the script:
   ```bash
   python evaluate_metrics.py
   ```

### 1. How We Tested
To generate realistic evaluation metrics, we ran the inference pipeline on a synthetic population generated by `synthetic_generator.py`. The synthetic population consists of normal users and  programmed insider threat users. After the scores were generated by `inference.py` and saved to `local_report_daily.csv`, we evaluated them using the `evaluate_metrics.py` script above.

### 2. Model Summary
The supervised classification model is highly conservative focused on known threats patterns, while the unsupervised anomaly detectors capture everything acting as sensitive tripwires. The Combined Ensemble averages their signals to balance them out providing the precision of the supervised model while retaining the broad recall of the unsupervised ones.

### 3. Understanding the Metrics Columns
- **Precision:** Percentage of alerts that are actual threats (minimizes false alarms).
- **Recall:** Percentage of actual threats that the model successfully caught.
- **F1-Score:** The mathematical balance between Precision and Recall.
- **AUC-ROC:** The model's ability to accurately rank threat days higher than normal days.
- **False Positive Rate:** Percentage of normal days incorrectly flagged as threats.
