## Prerequisites

---

## Steps to Reproduce

1. Open a PowerShell or Terminal window and navigate to the `local_pipeline` directory.
2. Open a Python shell:
   ```
   python
   ```
3. Import the inference module and pandas:
   ```python
   import pandas as pd
   from inference import _prepare_features
   ```
4. Create a raw mock DataFrame containing identifying columns (which should be ignored by the ML model) and `NaN` values (which crash the ML model):
   ```python
   raw_df = pd.DataFrame([{
       'user': 'test_user',
       'date': '2023-10-10',
       'usb_count': 5,
       'usb_count_zscore': float('nan') # Missing data!
   }])
   ```
5. Pass it through your custom data preparation layer:
   ```python
   clean_X, feature_cols = _prepare_features(raw_df)
   
   print(f"Ignored 'user' column? {'user' not in feature_cols}")
   print(f"Ignored 'date' column? {'date' not in feature_cols}")
   print(f"Filled NaN z-scores with 0? {clean_X['usb_count_zscore'].iloc[0] == 0}")
   ```
