# UI-03: Validate Settings panel triggers inference subprocess

**Test Type:** Integration  
**Status:** PASS  
**Reference:** `testing/phase_4/UI-03.md`

---

## Prerequisites

- Local API server running from the `server` directory on port 5001.
- A valid `local_model_intake.csv` and `synthetic_population.csv` must exist in `local_pipeline/output/`.

---

## Steps to Reproduce

1. Open **Postman** (or use the Dashboard UI).
2. Create a new `POST` request to `http://localhost:5001/api/run/inference`.
3. In the **Body** tab, select **raw** and **JSON**. Provide an optional threshold override:
   ```json
   {
     "threshold": 0.4500
   }
   ```
4. Click **Send** to trigger the inference subprocess.
5. Wait for the subprocess to complete (the terminal will calculate SHAP values which may take a few moments).

---

## Expected Output

The API correctly wraps the `inference.py` script in a `subprocess.run()`, overriding the base threshold to 0.45, recalculating scores, and returning the exact script output to the dashboard.

**Response:**
```json
{
  "ok": true,
  "output": "[infer] Loading trained models...\n[infer] Running unsupervised ensemble...\n[infer] Running supervised Random Forest..."
}
```
