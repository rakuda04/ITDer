# UI-04: Verify user selection correctly filters timeline and SHAP data

**Test Type:** Integration  
**Status:** PASS  

---

## Prerequisites

- Local API server running from the `server` directory on port 5001.
- Navigate your browser to `http://localhost:5001`.

---

## Steps to Reproduce

1. Open the dashboard in your web browser.
2. In the main view, observe the **Leaderboard** and **Timeline** sections.
3. Click on a specific user row in the Leaderboard (or use the dropdown if available in the UI layout).
4. Observe the **Timeline/Risk Trend** chart. It should instantly switch from showing aggregate data to showing only the selected user's risk scores over time.
5. Switch to the **SHAP / Explanation** tab (if available in the UI layout) for the same user.
6. Verify that the displayed features match the activity history for *only* that user.

---

## Expected Output

The React frontend state successfully intercepts the click event, filters the global `dailyAll` and `shapAll` arrays in-memory, and forces the Recharts timeline to re-render displaying only the target user's chronologically sorted data.
