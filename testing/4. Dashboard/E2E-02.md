# E2E-02: Verify dashboard-triggered run updates displayed results

**Test Type:** System  
**Status:** PASS  


---

## Prerequisites

- Server running (`docker compose up -d` from the `dist/server` directory).
- Browser pointing to `http://localhost:5001`.

---

## Steps to Reproduce

1. Open the dashboard in your web browser. Note the number of users on the leaderboard.
2. Open the **Settings** or **Admin** panel within the UI.
3. Change the synthetic generator settings (e.g., set Normal Users to `15` and Insider Users to `4`).
4. Click **"Run Synthetic Data"** directly inside the web UI. Wait for the success notification.
5. Click **"Run Inference"** directly inside the web UI. Wait for the success notification.
6. Refresh the dashboard (or rely on auto-refresh if implemented).
7. Check the Leaderboard to ensure it now displays exactly 19 synthetic users (15 normal + 4 insiders) plus any local users.

---

## Expected Output

The React application acts as a  command-and-control surface. It triggers backend Python processes via the Flask APIs, waits for execution to complete, and perfectly ingests the freshly generated CSV reports without requiring the analyst to touch a terminal.
