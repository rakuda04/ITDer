# E2E-01: Validate full pipeline data flow from endpoint to dashboard

**Test Type:** System  
**Status:** PASS  

---

## Prerequisites

- Windows Environment (or mock data present in the repo).
- Python 3.10+

---

## Steps to Reproduce

This is a true end-to-end trace testing every component of the architecture sequentially.

1. **Phase 1 (Server Backend & Dashboard):**
   Start the Dockerized server infrastructure first, so the ingest API is ready to receive data.
   ```bash
   cd dist/server
   docker compose up -d
   ```
2. **Phase 2 (Local Pipeline Installation & Execution):**
   Run the installer to deploy the local pipeline and push the first batch of data to the server.
   ```bash
   cd ../
   python installer.py
   ```

3. **Phase 3 (Verification):**
   Open a browser to `http://localhost:5001`. 
   Verify that your machine's user account ( `DESKTOP\YourName`) appears on the leaderboard alongside the synthetic population, assigned a calculated risk tier.

---

## Expected Output

Data flows cleanly from raw Windows UMDF registries, through the Pandas preprocessor filters, into the Machine Learning Ensembles, and finally serves seamlessly through the React application without a single fatal error or type mismatch.
