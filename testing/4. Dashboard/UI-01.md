# UI-01: Verify data APIs return correctly typed JSON

**Test Type:** Unit  
**Status:** PASS  

---

## Prerequisites

- Local API server running (`python api.py` from the `frontend` directory).
- Valid CSV reports must exist in the `local_pipeline/output/` directory.

---

## Steps to Reproduce

1. Open **Postman** (or a web browser).
2. Create a `GET` request to `http://localhost:5001/api/users`.
3. Examine the JSON response block. Pick one of the user rows and check the data types.
   - For example, `final_risk_score` should be a `float` (e.g., `45.2`, without quotes).
   - `rank` should be an `int` (e.g., `1`, without quotes).
4. Repeat the `GET` request for `http://localhost:5001/api/daily` and verify that fields like `total_active_minutes_day` are floats, and `job_site_visits_flag` is an integer.
5. Repeat the `GET` request for `http://localhost:5001/api/shap`.

---

## Expected Output

Because the API's `coerce_users`, `coerce_daily`, and `coerce_shap` functions safely convert the stringified CSV data back into Python native types before JSON serialization, the frontend receives mathematically workable data. 

**JSON Snippets Example:**

### `/api/users`
```json
{
  "user": "test_analyst",
  "rank": 1,
  "final_risk_score": 85.5,
  "is_synthetic": 0
}
```

### `/api/daily`
```json
{
  "user": "test_analyst",
  "date": "2023-10-10",
  "total_active_minutes_day": 120.5,
  "job_site_visits_flag": 0
}
```

### `/api/shap`
```json
{
  "user": "test_analyst",
  "date": "2023-10-10",
  "usb_count": 0.00569
}
```
